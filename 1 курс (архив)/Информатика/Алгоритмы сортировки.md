## 1. Сортировка пузырьком (Bubble Sort)
Самый простой алгоритм, который последовательно сравнивает соседние элементы и меняет их местами, если они стоят в неправильном порядке. Большие элементы постепенно «всплывают» в конец списка.

• Сложность: O(n²)
• Плюсы: Легкость реализации.

![[Pasted image 20260310104836.png]]

```python
import random, time
import matplotlib.pyplot as plt

def bubble_sort(A):
    A_copy = A.copy()
    n = len(A_copy)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if A_copy[j] > A_copy[j + 1]:
                A_copy[j], A_copy[j + 1] = A_copy[j + 1], A_copy[j]
                swapped = True
        if not swapped:
            break
    return A_copy

sizes = [10, 100, 500, 1000, 5000]
times = []

print("Прогрев: начат")
for _ in range(100):
    bubble_sort([random.randint(0, 100) for _ in range(100)])
print("Прогрев: окончен")

for size in sizes:
    arr = [random.randint(0, 100) for _ in range(size)]
    avg_time = 0
    for _ in range(10):
        start = time.perf_counter()
        bubble_sort(arr)
        avg_time += (time.perf_counter() - start)
    
    final_t = avg_time / 10
    times.append(final_t)
    print(f"Закончен подсчёт длины {size}:".ljust(40) + f"{final_t:.6f} сек.")

plt.plot(sizes, times, 'ro-')
plt.title('Bubble Sort Performance')
plt.xlabel('Размер данных (N)')
plt.ylabel('Время выполнения (T, сек)')
plt.grid(True)
plt.show()
```

## 2. Сортировка вставками (Insertion Sort)
Алгоритм разделяет массив на «отсортированную» и «неотсортированную» части. На каждом шаге элемент из неотсортированной части берется и вставляется на нужное место в отсортированную.

• Сложность: $O(n^2)$ 
• Плюсы: Эффективен для небольших или почти отсортированных массивов.
• Минусы: Медленный для больших случайных массивов.

![[Pasted image 20260310104900.png]]

```python
import random, time
import matplotlib.pyplot as plt

def insertion_sort(A):
    A_copy = A.copy()
    for i in range(1, len(A_copy)):
        key = A_copy[i]
        j = i - 1
        while j >= 0 and key < A_copy[j]:
            A_copy[j + 1] = A_copy[j]
            j -= 1
        A_copy[j + 1] = key
    return A_copy

sizes = [10, 100, 500, 1000, 5000]
times = []

print("Прогрев: начат")
for _ in range(100):
    insertion_sort([random.randint(0, 100) for _ in range(100)])
print("Прогрев: окончен")

for size in sizes:
    arr = [random.randint(0, 100) for _ in range(size)]
    avg_time = 0
    for _ in range(10):
        start = time.perf_counter()
        insertion_sort(arr)
        avg_time += (time.perf_counter() - start)
    
    final_t = avg_time / 10
    times.append(final_t)
    print(f"Закончен подсчёт длины {size}:".ljust(40) + f"{final_t:.6f} сек.")

plt.plot(sizes, times, 'bo-')
plt.title('Insertion Sort Performance')
plt.xlabel('Размер данных (N)')
plt.ylabel('Время выполнения (T, сек)')
plt.grid(True)
plt.show()
```

## 3. Сортировка слиянием (Merge Sort)
Относится к стратегии «разделяй и властвуй». Массив рекурсивно разбивается пополам до единичных элементов, а затем эти части сливаются обратно в правильном порядке.

• Сложность: O(n log n)
• Плюсы: Стабильно высокая скорость на больших данных.

![[Pasted image 20260310104921.png]]

```python
import random, time
import matplotlib.pyplot as plt

def merge_sort(A):
    if len(A) <= 1:
        return A
    
    mid = len(A) // 2
    left = merge_sort(A[:mid])
    right = merge_sort(A[mid:])
    
    return merge(left, right)

def merge(left, right):
    res = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            res.append(left[i]); i += 1
        else:
            res.append(right[j]); j += 1
    res.extend(left[i:]); res.extend(right[j:])
    return res

sizes = [10, 100, 500, 1000, 5000]
times = []

print("Прогрев: начат")
for _ in range(100):
    merge_sort([random.randint(0, 100) for _ in range(100)])
print("Прогрев: окончен")

for size in sizes:
    arr = [random.randint(0, 100) for _ in range(size)]
    avg_time = 0
    for _ in range(10):
        start = time.perf_counter()
        merge_sort(arr)
        avg_time += (time.perf_counter() - start)
    
    final_t = avg_time / 10
    times.append(final_t)
    print(f"Закончен подсчёт длины {size}:".ljust(40) + f"{final_t:.6f} сек.")

plt.plot(sizes, times, 'go-')
plt.title('Merge Sort Performance')
plt.xlabel('Размер данных (N)')
plt.ylabel('Время выполнения (T, сек)')
plt.grid(True)
plt.show()
```
