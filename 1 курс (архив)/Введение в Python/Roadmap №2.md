## Списки

Списки в Python — это упорядоченные последовательности элементов, которые являются **изменяемыми**. Это означает, что можно модифицировать их содержимое после создания.

- **Создание:** Списки определяются с помощью квадратных скобок `[]` или конструктора `list()`.
    
- **Индексация и срезы:** Элементы индексируются с 0. Срезы (slicing) позволяют извлекать части списка с помощью синтаксиса `list[start:stop:step]`.
    
- **Методы изменения:**
    
    - `append(x)`: добавляет элемент в конец.
        
    - `insert(i, x)`: вставляет элемент в указанную позицию.
        
    - `remove(x)`: удаляет первый элемент со значением x.
        
    - `pop(i)`: удаляет и возвращает элемент по индексу (по умолчанию последний).
        
- **Особенности:** Списки могут содержать элементы разных типов, хотя чаще всего используются для хранения однородных объектов.

## Кортежи

Кортежи — это упорядоченные последовательности, которые являются **неизменяемыми**. После создания кортежа его содержимое нельзя изменить.

- **Создание:** Обычно определяются в круглых скобках `()`, но технически их создает запятая между элементами.
    
- **Упаковка и распаковка (Packing & Unpacking):**
    
    - **Упаковка:** Присваивание нескольких значений одной переменной: `t = 123, 456`.
        
    - **Распаковка:** Присваивание значений кортежа нескольким переменным: `x, y = t`.
        
- **Особенности:** Кортежи работают быстрее списков и потребляют меньше памяти. Они часто используются для хранения гетерогенных (разнородных) данных, которые не должны меняться.
