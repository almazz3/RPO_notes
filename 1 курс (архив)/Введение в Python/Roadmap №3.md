## 1. Структура кода и оформление

В отличие от других языков, использующих `{}` для блоков кода, Python строго полагается на отступы. Стандарт — **4 пробела**. Ошибка в отступах вызовет `IndentationError`. Каждая инструкция обычно пишется с новой строки. Точка с запятой `;` на конце не требуется. Если выражение слишком длинное, его можно перенести с помощью обратного слэша `\` или неявно, используя круглые/квадратные скобки `()`, `[]`:

```python
total = item_one + \
        item_two # Явный перенос

numbers = [
    1, 2, 3,
    4, 5, 6
] # Неявный перенос
```

 Однострочные: начинаются с символа `#`.  Многострочные/Документирование: технически оформляются строками в тройных кавычках `"""` или `'''`, которые не присвоены переменной.
## 2. Идентификаторы и переменные

- **Регистрозависимость:** Переменные `age`, `Age` и `AGE` — это три абсолютно разные переменные.
   
- **Правила именования:**
    
    - Начинаются с латинской буквы или нижнего подчеркивания `_`.
    
    - Не могут начинаться с цифры и содержать спецсимволы вроде `@`, `$`, `%`.
       
    - Нельзя использовать зарезервированные ключевые слова (например, `if`, `class`, `import`).
    
- **Конвенции (`_`):**
    
    - Имена классов начинаются с большой буквы.
       
    - `_private`: одинарное подчеркивание намекает на приватность элемента внутри модуля/класса.
    
    - `__strongly_private`: двойное подчеркивание вызывает искажение имени (name mangling) для защиты.
       
    - `__init__`: системные «магические» методы (dunder-методы).
       

## 3. Базовые типы данных и операции

### Динамическая типизация

Тип переменной определяется автоматически в момент присваивания значения.

```python
x = 5          # Целое число (int)
y = 3.14       # Число с плавающей точкой (float)
name = "Alice" # Строка (str)
is_valid = True # Булево значение (bool)
```

### Логические операции и сравнения

- Равенство: `==`, неравенство: `!=`.

- Логические операторы пишутся словами: `and`, `or`, `not`.

- Оператор `is` проверяет идентичность (указывают ли две переменные на один и тот же объект в памяти), в то время как `==` проверяет равенство значений.
   

## 4. Коллекции (Структуры данных)

- **Списки (Lists):** Изменяемые упорядоченные последовательности.

```python
li = [1, 2, 3]
li.append(4)     # Добавить в конец -> [1, 2, 3, 4]
li.pop()         # Удалить и вернуть последний элемент
```

- **Кортежи (Tuples):** Неизменяемые аналоги списков. Одноэлементный кортеж требует запятой: `(1,)`.

```python
tup = (1, 2, 3)
```

- **Срезы (Slices):** Позволяют извлекать подстроки или части коллекций в формате `[start:stop:step]`.

```python
li[1:3]          # Элементы с индекса 1 по 2 (не включая 3)
li[::-1]         # Развернуть список/строку наоборот
```

## 5. Управляющие конструкции

Каждая конструкция, объявляющая блок кода, завершается двоеточием `:`.

```python
# Условный оператор
if age >= 18:
    print("Доступ разрешен")
elif age > 14:
    print("Требуется разрешение родителей")
else:
    print("Доступ запрещен")

# Цикл For (итерация по коллекции или диапазону)
for i in range(5): # range(5) генерирует числа от 0 до 4
    print(i)
```

## 6. Точка входа в скриптах

Для того чтобы код выполнялся только тогда, когда файл запущен как самостоятельный скрипт (а не импортирован как модуль в другой файл), используется специальная проверка `__name__`:

```python
def main():
    print("Этот код работает только при прямом запуске файла")

if __name__ == "__main__":
    main()
```
