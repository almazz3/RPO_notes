#Windows #Tools #WinGet #CLI #Automation

**WinGet** (Windows Package Manager) — это официальный менеджер пакетов от Microsoft для командной строки, который позволяет искать, устанавливать, обновлять и удалять приложения в Windows 10 и 11.

## Основные команды

|**Команда**|**Описание**|
|---|---|
|`winget search <имя>`|Поиск приложения в репозиториях|
|`winget install <имя/ID>`|Установка приложения|
|`winget list`|Список всех установленных программ|
|`winget upgrade`|Показать список программ, для которых есть обновления|
|`winget upgrade --all`|Обновить **все** установленные программы до последних версий|
|`winget uninstall <имя>`|Удаление приложения|

## Полезные примеры
### Экспорт и импорт списка программ

Полезно при переезде на новый компьютер или после переустановки Windows.

1. **Экспорт** (создаст JSON-файл со списком всех ваших программ):

```PowerShell
winget export -o C:\path\to\apps_list.json
```

2. **Импорт** (автоматически установит всё из списка):
  
``` PowerShell
winget import -i C:\path\to\apps_list.json
```

## Лайфхаки

- **Поиск по ID:** Если поиск выдает много результатов, лучше использовать ID (например, `Microsoft.VisualStudioCode`), чтобы установить именно то, что нужно.

- **Интерактивный режим:** Если не уверены в названии, введите часть имени, и winget предложит выбрать из списка.

- **Автоматизация:** Команда `winget upgrade --all` — отличный способ поддерживать весь софт в актуальном состоянии одной командой.
