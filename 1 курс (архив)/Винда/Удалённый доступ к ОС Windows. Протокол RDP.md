#Windows #RDP 
## Введение

Процесс удалённого подключения к другой системе на ОС Windows можно осуществить несколькими различными способами, одним из которых является подключение через встроенную утилиту подключения Windows 10, реализующую протокол RDP (Remote Desktop Protocol).

## Что такое RDP?

**RDP (Remote Desktop Protocol)** — это проприетарный протокол прикладного уровня, разработанный компанией **Microsoft**. Он предназначен для обеспечения удалённого доступа пользователя к серверу или рабочей станции под управлением ОС Windows с возможностью управления графическим интерфейсом (GUI).

По сути, RDP передает экран удаленного компьютера на устройство, а в обратную сторону транслирует нажатия клавиш клавиатуры и движения мыши.

- **Порт по умолчанию:** `3389` (работает поверх TCP и UDP)

## Как подключиться (Пошаговый алгоритм)

### 1. Подготовка удаленного ПК 

1. Открыть **Параметры** — **Система** — **Удаленный рабочий стол**.
![[Pasted image 20260604125438.png]]
    
2. Установить переключатель "Включить удаленный рабочий стол" в положение **Вкл.**
    
3. Убедиться, что у учетной записи пользователя, под которой будем заходить, **задан пароль** (без пароля RDP по умолчанию не пустит из соображений безопасности).
    

### 2. Подключение с клиентского ПК

1. Нажать комбинацию клавиш `Win + R`, ввести `mstsc` и нажать **Enter** (это запустит встроенную утилиту "Подключение к удаленному рабочему столу").
    
2. В появившемся окне ввести **IP-адрес** или **имя** удаленного компьютера.
    
3. Нажать **Подключиться**.
    
4. Ввести имя пользователя и пароль от удаленной машины.

## Важные нюансы и ограничения при работе с RDP

При использовании RDP стоит учитывать ряд технических и архитектурных особенностей:

### 1. Ограничения редакций Windows (Лицензирование)

>  **Главное ограничение:** Можно подключиться _к_ компьютеру по RDP только в том случае, если на нем установлена редакция **Windows Pro (Профессиональная), Enterprise (Корпоративная) или Server**. На редакциях **Windows Home (Домашняя)** серверная часть RDP заблокирована. Использовать "Домашнюю" Windows можно _только в качестве клиента_ (с нее подключаться можно, к ней — нет).

### 2. Однопользовательский режим в десктопных версиях

В клиентских версиях Windows (10/11 Pro) одновременно в системе может работать **только один пользователь**. Если подключиться по RDP к ПК, за которым в этот момент физически кто-то сидит, этого пользователя "выбьет" на экран блокировки. Многопользовательский режим поддерживают только версии Windows Server.

### 3. Безопасность и Сеть (NLA и VPN)

- **В локальной сети vs Через Интернет:** По умолчанию RDP предназначен для работы внутри защищенной локальной сети. Открывать порт `3389` напрямую наружу в интернет — огромный риск (его быстро взломают брутфорсом). Для безопасного подключения через интернет используют **VPN** или **RDP Gateway**.
    
- **NLA (Network Level Authentication):** Всегда оставляйте включенной проверку подлинности на уровне сети. Она требует аутентификации пользователя _до_ установления полноценного RDP-сеанса, что защищает от DOS-атак.
    

### 4. Полезные фичи при подключении

В окне `mstsc` перед нажатием кнопки "Подключиться" можно развернуть вкладку **"Показать параметры"**:

- **Локальные ресурсы:** Можно "пробросить" свой буфер обмена, локальные диски или принтер внутрь удаленной сессии.
    
- **Экран:** Настройка разрешения и использование нескольких мониторов (галочка "Использовать все мои мониторы").
