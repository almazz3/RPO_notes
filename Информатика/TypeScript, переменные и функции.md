## 1. Переменные и константы

TypeScript использует те же ключевые слова для объявления данных, что и современный JavaScript, но с возможностью строгой типизации.

### Основные способы объявления:

1. **`let`**: Основной способ объявления переменной. Имеет **блочную область видимости**. Не позволяет повторно объявлять переменную с тем же именем в одном блоке.
    
2. **`const`**: Используется для создания констант. Значение должно быть присвоено при объявлении и не может быть изменено позже.
    
3. **`var`**: Устаревший способ. Имеет функцию или глобальную область видимости, игнорируя блоки `{}` (кроме функций). Позволяет повторное объявление, что часто ведет к ошибкам.
    

### Область видимости и скрытие (Shadowing)

Переменные во вложенных блоках кода могут "скрывать" внешние переменные с тем же именем.



```TypeScript
let x = 10;
{
    let x = 25; // Эта x доступна только внутри этого блока
    console.log(x); // Выведет 25
}
console.log(x); // Выведет 10
```

## 2. Функции в TypeScript

Функции позволяют группировать логику. В TS мы можем строго определять типы входящих параметров и возвращаемого значения.

### Синтаксис и типы

Тип возвращаемого значения указывается после двоеточия после списка параметров.

TypeScript

```TypeScript
function add(a: number, b: number): number {
    return a + b;
}

// Стрелочная функция
const multiply = (x: number, y: number): number => x * y;
```

### Параметры функций

1. **Необязательные параметры (`?`)**: Должны идти после обязательных.
    
2. **Параметры по умолчанию**: Значение присваивается через `=`.
    
3. **Неопределенный набор параметров (`Rest parameters`)**: Используется оператор `...` для передачи массива аргументов.
    

TypeScript

```TypeScript
// Пример со всеми видами параметров
function buildName(firstName: string, lastName?: string, prefix: string = "Mr."): string {
    return lastName ? `${prefix} ${firstName} ${lastName}` : `${prefix} ${firstName}`;
}

console.log(buildName("Ivan"));              // Mr. Ivan
console.log(buildName("Ivan", "Ivanov", "Dr.")); // Dr. Ivan Ivanov

// Rest parameters
function sumAll(...numbers: number[]): number {
    return numbers.reduce((acc, curr) => acc + curr, 0);
}
```

## Итоги (Cheat Sheet)

|**Инструмент**|**Описание**|
|---|---|
|`let` / `const`|Используй вместо `var` для предсказуемой области видимости.|
|`readonly`|Похоже на `const`, но применяется к свойствам классов или интерфейсов.|
|`void`|Тип возвращаемого значения для функций, которые ничего не возвращают.|
|`?`|Делает параметр функции или свойство объекта необязательным.|
