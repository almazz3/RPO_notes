## 1. Подготовка и системные требования

Перед началом нужно убедиться, что железо (или выделенные ресурсы в VM) соответствует минимуму. К 2026 году требования «комфорта» немного выросли по сравнению с релизными.

| Компонент | Минимум        | Рекомендуется (для работы)    |
| --------- | -------------- | ----------------------------- |
| Процессор | 1 ГГц (2 ядра) | 2.5 ГГц+ (4 ядра+)            |
| ОЗУ       | 2 ГБ (x64)     | 8 ГБ+                         |
| Диск      | 32 ГБ          | 64 ГБ+ (SSD крайне желателен) |
| Графика   | DirectX 9      | DirectX 12                    |

### Создание загрузочного носителя

1. Скачиваем Media Creation Tool с сайта Microsoft. Либо используем Rufus (рекомендуется для обхода ограничений и тонкой настройки ISO).
2. Для VM: скачиваем .iso образ.

---

## 2. Основные этапы установки

1. Загрузка: Выставь в BIOS/UEFI приоритет загрузки с USB (или подключаем ISO к виртуальному приводу).
2. Выбор версии: Если есть выбор, ставим Pro — в ней больше инструментов для администрирования и отключения «лишнего».
3. Тип установки: Всегда выбираем «Выборочная: только установка Windows» (Custom), чтобы сделать чистую установку.
4. Разметка диска:
	* На чистом диске нажимаем «Далее» — Windows сама создаст нужные разделы (EFI, MSR, Recovery).
	* Если диск уже использовался — удаляем все старые разделы, пока не останется одно «Незанятое пространство».

---

## 3. Особенности установки на Виртуальные Машины (VM)

### Ресурсы и железо

* Тип диска: Всегда выбираем Dynamic Allocation (динамический), чтобы файл ВМ не занимал сразу 60 ГБ на физическом диске.
* Virtualization Technology: Нужно убедиться, что в BIOS хоста включены VT-x (Intel) или AMD-V.
* Тип контроллера: Для SSD в VM лучше выбирать NVMe или SATA (в зависимости от поддержки гипервизора).

### Специфические нюансы для VirtualBox:

* Обязательно включаем «3D-ускорение» в настройках дисплея, иначе интерфейс будет лагать.
* После установки выбираем в меню: Устройства -> Подключить образ диска дополнений гостевой ОС.

---

## 4. Пост-установка (Чек-лист)

* [ ] Драйверы: Проверяем Диспетчер устройств (в VM это решается установкой Tools/Additions).
* [ ] Обновления: Заходим в Центр обновления. К 2026 году Windows 10 находится на этапе расширенной поддержки — патчи безопасности критичны.
* [ ] Конфиденциальность: Отключаем телеметрию и рекламные идентификаторы в настройках.
* [ ] Удаление мусора: Используем скрипты (например, *Chris Titus Tech's Windows Utility*) для удаления предустановленных игр и приложений.
