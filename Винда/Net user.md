**NET** — это стандартный набор консольных утилит для управления пользователями и группами в **Windows** через *командную строку* (*CMD*) или *PowerShell*.

**Основные возможности и команды:

| №   | Действие                       | Команда                                               |
| --- | ------------------------------ | ----------------------------------------------------- |
| 1   | Просмотр списка пользователей  | `net user`                                            |
| 2   | Изменение пароля пользователя  | `net user [имя_пользователя] [новый_пароль]`          |
| 3   | Просмотр данных пользователя   | `net user [имя_пользователя]`                         |
| 4   | Просмотр локальных групп       | `net localgroup`                                      |
| 5   | Добавление в локальную группу  | `net localgroup [имя_группы] [имя_пользователя] /add` |
| 6   | Пароль не ограничен по времени | `net user [имя_пользователя] /expires:never`          |
| 7   | Удаление пользователя          | `net user [имя_пользователя] /delete`                 |
Дополнительные полезные параметры (пункт 6)
 * Запрет на изменение пароля: `net user [имя_пользователя] /passwordchg:no`
 * Сделать пароль "бесконечным" (через WMIC):
   `wmic useraccount where name='имя' set passwordexpires=false`
> [!WARNING] Важно
> Для выполнения большинства этих команд терминал должен быть запущен от имени Администратора.
