# Задача

Нужно создать программу, которая принимает от пользователя строку-пароль и проверяет, соответствует ли она базовым критериям безопасности.

```python
user_password = input("Введите пароль (от 8 символов): ")

if len(user_password) < 8:
    print("Ошибка: Пароль слишком короткий!")
else:
    has_upper = False
    has_lower = False
    has_digit = False

    for char in user_password:
        if char.isupper():
            has_upper = True
        if char.islower():
            has_lower = True
        if char.isdigit():
            has_digit = True    
    
    if has_upper and has_lower and has_digit:
        print("Пароль надежный и принят!")
    else:
        print("Ошибка: Пароль слишком слабый! Должны быть заглавные, строчные буквы и цифры.")
```
