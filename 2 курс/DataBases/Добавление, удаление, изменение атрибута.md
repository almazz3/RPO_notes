Создание атрибута: 
```sql
ALTER TABLE Название_сущности
ADD Название_атрибута
```

Пример: Добавим в сущность Блюдо атрибут "Вес порции (г)".
```sql
ALTER TABLE Блюдо
ADD Вес_порции INT NULL;

SELECT * FROM Блюдо
```

Пример 2: Добавим в Ингредиент атрибут "Калорийность" с ограничением CHECK:

```sql
ALTER TABLE Ингредиент
ADD Калорийность INT NOT NULL
CHECK (Калорийность >= 0);

SELECT * FROM Ингредиенты
```

```sql
ALTER TABLE Ингредиент
ADD Калорийность INT NOT NULL
CONSTRAINT CH_Ингредиент_Калорийность CHECK (Калорийность >= 0);

SELECT * FROM Ингредиенты
```

```sql
UPDATE Название_сущности
SET Атрибут
```

```sql
UPDATE Блюдо
SET Всего_ингредиентов = 1;
```

```sql
UPDATE Блюдо
SET Всего_ингредиентов = (
	SELECT COUNT(*)
	FROM Состав
	WHERE ID_блюда = Блюдо.ID
)

SELECT * FROM Блюдо
```

## Изменение атрибута

Пример: Не хватает заявленного ранее диапозона для описания кухни (NVARCHAR(100)). Расширим Описание в Кухня:
```sql
ALTER TABLE Кухня
ALTER COLUMN Описание NVARCHAR(255) NULL;
```
