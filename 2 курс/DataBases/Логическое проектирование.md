## Ограничения в SQL
1. NULL/NOT NULL - Гарантирует, что в атрибуте будет или не будет значения.
2. UNIQUE - Обеспечивает уникальность значений в атрибуте или группе атрибутов.
3. PRIMARY KEY (Первичный ключ) - Однозначно идентифицирует каждую строку в сущности.
4. FOREIGN KEY (Внешний ключ) - Он гарантирует, что значения в атрибуте (или в группе атрибутов) внешнего ключа в одной сущности соответствуют существующим значениям в первичном ключе другой сущности. Создаёт связь между двумя сущностями.
5. CHECK - Он служит для проверки значений по определённому условию.
6. DEFAULT - Устанавливает значение по умолчанию.
