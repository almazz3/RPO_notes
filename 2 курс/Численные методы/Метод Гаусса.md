## Входные данные
1. Размерность системы $n$ — количество уравнений и неизвестных
2. Матрица коэффициентов $A=(a_{ij})$ размером $n\cdot n$
3. Вектор свободных членов $b=(b_i)$
4. Точность вычислений $\varepsilon$, используемая для проверки числовых значений, например $0{,}001$
## Выходные данные
1. Вектор решения $x=(x_1,x_2,\ldots,x_n)$ — вектор решения
2. Вектор невязок $r=(r_1,r_2,\ldots,r_n)$ — отклонения при подстановке решения в исходную систему
3. Максимальная абсолютная невязка $r_{\max}$ — наибольшее по модулю значение невязки
## Алгоритм
1. Проверка начальных условий.
	1. Проверить, что размерность матрицы соответствует введённому значению $n$
	2. Проверить, что все введённые коэффициенты являются числовыми значениями
	3. Проверить наличие ненулевого ведущего элемента в текущем столбце. Если ведущий элемент равен нулю, переставить текущую строку с одной из нижних строк, в которой соответствующий элемент отличен от нуля
	4. Если подходящую строку найти невозможно, определить, что система не имеет единственного решения, и завершить вычисления с соответствующим сообщением
2. Прямой ход метода Гаусса.
	1. Последовательно рассматривать столбцы матрицы от первого до предпоследнего
	2. Для каждого столбца выбрать ведущую строку и при необходимости поменять строки местами
	3. Для каждой строки $i$, расположенной ниже ведущей строки $k$, вычислить коэффициент исключения: $m_{ik}=\frac{a_{ik}}{a_{kk}}$
	4. Выполнить преобразование строки: $a_{ij}=a_{ij}-m_{ik}a_{kj},$ $b_i=b_i-m_{ik}b_k$
	5. Повторять преобразования, пока матрица не примет верхнетреугольный вид
3. Обратный ход метода Гаусса.
	1. Начать вычисление неизвестных с последнего уравнения
	2. Найти последнее неизвестное: $x_n=\frac{b_n}{a_{nn}}$
	3. Последовательно вычислять остальные неизвестные по формуле: $x_i=\frac{b_i-\sum_{j=i+1}^{n}a_{ij}x_j}{a_{ii}}$
	4. Продолжать вычисления до определения всех неизвестных $x_1,x_2,\ldots,x_n$
4. Оценка погрешности решения.
	1. Подставить найденные значения неизвестных в исходную систему уравнений
	2. Вычислить невязку для каждого уравнения: $r_i=\sum_{j=1}^{n}a_{ij}x_j-b_i$
	3. Определить максимальную абсолютную невязку: $r_{\max}=\max_{1\leq i\leq n}|r_i|$
	4. Сравнить максимальную невязку с заданной точностью $\varepsilon$. Если $r_{\max}\leq\varepsilon$, считать решение удовлетворяющим установленному критерию невязки. В противном случае сообщить, что критерий не выполнен
5. Вывод результатов.
	1. Вывести найденные значения неизвестных $x_1,x_2,\ldots,x_n$
	2. Вывести значения невязок и максимальную абсолютную невязку $r_{\max}$
	3. Вывести сообщение о выполнении или невыполнении критерия точности
	4. Округлить результаты до количества знаков после запятой, соответствующего заданной точности. Например, при точности $0{,}001$ выводить три знака после запятой

## Код
```python
import math

def gauss_method(A, b, eps):
    n = len(A)
    tol = 1e-12

    # Сохраняем исходные данные для вычисления невязки
    A_original = [row[:] for row in A]
    b_original = b[:]

    # Формируем расширенную матрицу
    M = [A[i][:] + [b[i]] for i in range(n)]

    # Прямой ход метода Гаусса
    pivot_row = 0
    pivot_cols = []

    for col in range(n):
        if pivot_row >= n:
            break

        # Выбор ведущего элемента
        max_row = max(
            range(pivot_row, n),
            key=lambda i: abs(M[i][col])
        )

        # Если ведущий элемент близок к нулю, пропускаем столбец
        if abs(M[max_row][col]) < tol:
            continue

        # Перестановка строк
        M[pivot_row], M[max_row] = M[max_row], M[pivot_row]

        # Исключение неизвестной из нижних строк
        for i in range(pivot_row + 1, n):
            factor = M[i][col] / M[pivot_row][col]
            M[i][col] = 0.0

            for j in range(col + 1, n + 1):
                M[i][j] -= factor * M[pivot_row][j]

        pivot_cols.append(col)
        pivot_row += 1

    # Проверка совместности системы
    for i in range(n):
        if max(abs(M[i][j]) for j in range(n)) < tol:
            if abs(M[i][n]) >= tol:
                return None, "Система не имеет решений", None

    # Проверка единственности решения
    if len(pivot_cols) < n:
        return None, "Система не имеет единственного решения", None

    # Обратный ход метода Гаусса
    x = [0.0] * n

    for i in range(n - 1, -1, -1):
        col = pivot_cols[i]

        s = sum(M[i][j] * x[j] for j in range(col + 1, n))
        x[col] = (M[i][n] - s) / M[i][col]

    # Вычисление невязки по исходной системе
    residuals = []

    for i in range(n):
        value = sum(A_original[i][j] * x[j] for j in range(n))
        residuals.append(value - b_original[i])

    max_residual = max(abs(r) for r in residuals)

    return x, residuals, max_residual


# Ввод исходных данных
n = int(input("Введите размерность системы n: "))
eps = float(input("Введите точность eps: "))

if n <= 0 or eps <= 0:
    raise ValueError("Размерность и точность должны быть положительными.")

print("Введите матрицу коэффициентов A:")
A = []

for i in range(n):
    row = list(map(float, input().split()))

    if len(row) != n:
        raise ValueError("В каждой строке должно быть n коэффициентов.")

    A.append(row)

print("Введите вектор свободных членов b:")
b = list(map(float, input().split()))

if len(b) != n:
    raise ValueError("Вектор b должен содержать n элементов.")

# Решение системы
x, residuals, max_residual = gauss_method(A, b, eps)

# Вывод результатов
if residuals is None:
    print(x)
else:
    digits = max(0, math.ceil(-math.log10(eps)))

    print("\nРешение системы:")
    for i in range(n):
        print(f"x{i + 1} = {x[i]:.{digits}f}")

    print("\nНевязки:")
    for i, r in enumerate(residuals):
        print(f"r{i + 1} = {r:.{digits}f}")

    print(f"\nМаксимальная абсолютная невязка: "
          f"{max_residual:.{digits}f}")

    if max_residual <= eps:
        print("Критерий точности по невязке выполнен.")
    else:
        print("Критерий точности по невязке не выполнен.")
```
