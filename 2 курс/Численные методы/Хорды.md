## Входные данные
$f$ - непрерывная функция
$a$ - начало отрезка
$b$ - конец отрезка
$E$ - точность ($E\le 0$)
## Выходные данные
$x$ - искомый корень
$f(x)$ - значение ф-ии в корне
## Алгоритм
1. Если $E\leq0$ вывести ошибку и завершить
2. Если $a > b$ поменять значения местами
3. Если $f(a)\cdot f(b)\ge0$ вывести результат "Начальный отрезок не удовлетворяет условию", завершить
4. Находим хорду $\Large c=a-f(a)\cdot\frac{b-a}{f(b)-f(a)}$
5.  Пока $|f(c)|\ge E$
	1. Если $f(a)*f(c)<0$ то $b=c$ иначе $a=c$
	2. Пересчитать хорду $\Large c=a-f(a)\cdot\frac{b-a}{f(b)-f(a)}$
6. Вывод $x=c$ и $f(x)$, завершить
## Код
```python
import math

expr = input("Введите функцию f(x): ") #при проверке других вариантов советую перед формулой написать math.
a = float(input("Введите начало отрезка (a): "))
b = float(input("Введите конец отрезка (b): "))
e = float(input("Введите точность: "))

def f(x):
    return eval(expr, {"x": x, "math": math}) #преобразование функции для дальнейших вычислений

if e <= 0:
    print("Точность меньше или равна нулю")
    exit()

if a > b:
    a, b = b, a

if f(a) * f(b) >= 0:
    print("Начальный отрезок не удовлетворяет условию")
    exit()

c = a - f(a) * ((b - a)/(f(b)-f(a)))

while abs(f(c)) >= e:
    if f(a)*f(c) < 0:
        b = c
    else:
        a = c
    c = a - f(a) * ((b - a)/(f(b)-f(a)))

x = c
print(x, f(x))
```
