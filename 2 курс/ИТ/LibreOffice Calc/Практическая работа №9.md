## Часть 1. Работа с рисунками в документе (LibreOffice Writer)

### 1.1. Вставка рисунка
1. Открыть новый документ: **Файл → Создать → Текстовый документ**.
2. Выбрать место курсора и выполнить **Вставка → Изображение → Из файла**.
3. Указать файл рисунка и нажать «Открыть».
4. При необходимости изменить размер, перетаскивая маркеры по углам рисунка с нажатой клавишей Shift, чтобы сохранить пропорции.
### 1.2. Создание блок-схемы
1. Выполнить **Вставка → Рисунок → Новый рисунок**, либо использовать панель **Фигуры**.
2. На панели **Фигуры** выбрать элементы блок-схемы: «Процесс», «Решение», «Начало/конец», «Данные».
3. Разместить фигуры на холсте и соединить их соединительными линиями.
4. Подписать блоки: двойным щелчком по фигуре ввести текст.

### 1.3. Переупорядочивание слоёв и вращение фигур

1. Выделить фигуру и открыть контекстное меню **Положение → Перенести наверх / Перенести вниз**, чтобы изменить порядок наложения слоёв.
2. Для поворота использовать маркер вращения над фигурой либо **Формат → Положение и размер → Поворот**, задав угол в градусах.

### 1.4. Рисунок-подложка для текста

1. Вставить изображение (например, логотип или схему).
2. Открыть **Формат → Изображение → Свойства → Обтекание**, выбрать вариант **Фон** (или **Через текст** с низкой прозрачностью).
3. Установить прозрачность в **Свойствах → Прозрачность**, чтобы текст оставался читаемым.
4. Переместить изображение на задний план: **Положение → Перенести на задний план**.

### 1.5. Управление обтеканием текстом

Варианты обтекания, которые проверены в работе:

- **Без обтекания**: рисунок располагается отдельно от текста;
- **Вокруг контура**: текст огибает форму рисунка;
- **Сверху и снизу**: текст идёт над и под рисунком;
- **Через текст**: рисунок находится на фоне текста.

Для настройки выбрать рисунок, затем **Формат → Обтекание** и сравнить результат.

### 1.6. Работа с научными формулами

1. Вставить объект: **Вставка → Объект → Формула**.
2. В редакторе формул ввести, например, квадратное уравнение: `x = {-b +- sqrt{b^2 - 4ac}} over {2a}`.
3. Выйти из редактора, щёлкнув за пределами формулы. Формулу можно переместить и выровнять по центру.

## Часть 2. Табличный процессор LibreOffice Calc

### 2.1. Создание книги и форматирование

1. Создать книгу: **Файл → Создать → Электронная таблица**.
2. Заполнить таблицу данными, например ведомостью успеваемости.
3. Оформить таблицу: выделить диапазон, выбрать **Формат → Ячейки** (границы, заливка, шрифт, выравнивание).
4. Задать числовой формат для денежных или процентных значений.
5. Переименовать листы через контекстное меню ярлыка листа.

### 2.2. Формулы

Использованные формулы:

- Сумма: `=СУММ(B2:B10)`
- Среднее: `=СРЗНАЧ(B2:B10)`
- Максимум и минимум: `=МАКС(B2:B10)`, `=МИН(B2:B10)`
- Условие: `=ЕСЛИ(B2>=3;"Зачёт";"Незачёт")`

### 2.3. Специальные возможности

- Автозаполнение формул протягиванием маркера в правом нижнем углу ячейки.
- Условное форматирование: **Формат → Условное форматирование**, например подсветка ячеек со значением меньше 3.
- Сортировка и фильтрация: **Данные → Сортировать / Автофильтр**.
- Диаграмма по данным: **Вставка → Диаграмма**.

### 2.4. Макросы

В LibreOffice Calc макросы пишутся на языке **LibreOffice Basic**, который близок к Visual Basic.

Порядок создания: **Сервис → Макросы → Редактировать макросы → Standard → Module1**. Пример простого макроса:

```basic
Sub СчитатьСумму
    Dim oSheet As Object
    Dim nSum As Double
    oSheet = ThisComponent.Sheets(0)
    nSum = oSheet.getCellRangeByName("B2:B10").getDataArray()
    MsgBox "Сумма выделенного диапазона выведена в ячейку B12"
    oSheet.getCellRangeByName("B12").setValue(Application.WorksheetFunction.Sum(...))
End Sub
```

_Примечание: приведённый выше код нужно доработать под конкретную задачу. Для суммы проще использовать формулу `=СУММ(B2:B10)`._
