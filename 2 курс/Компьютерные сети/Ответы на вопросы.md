1. Среды передачи данных - это каналы связи, соединяющие узлы сети. Она может быть как проводной, так и беспроводной. 
	Виды передачи данных:
	- Симплексная - передача идёт в одну сторону
	- полудуплексная - передача идёт в обе стороны попеременно
	- полнодуплексная - передача идёт в обе стороны
2. **Доступ к среде передачи данных** - это процесс управления разрешением на передачу сигналов данных сетевым объектам в общей среде. 
	**Метод доступа** - это набор правил, которые определяют, как компьютер должен отправлять и принимать данные по сетевому кабелю.
	**Конфликт доступа** - это ситуация, возникающая при попытке одновременного доступа к общей среде передачи нескольких узлов: когда две или более станции пытаются послать данные в одно и то же время.
3. Существуют 3 стандартных метода доступа:
	- **CSMA/CD** (Carrier Sense Multiple Access / Collision Detection);
	- **CSMA/CA** (Carrier Sense Multiple Access / Collision Avoidance);
	- **Маркерные методы** (Маркерная шина IEEE 802.4, Маркерное кольцо IEEE 802.5).
4. Методы классифицируются следующим образом:
	1. **Централизованные** — все управление сосредоточено в одном главном узле (центре/сервере).
	    - _Достоинство:_ отсутствие конфликтов.
	    - _Недостатки:_ неустойчивость к отказам центра, малая гибкость.
	2. **Децентрализованные** — управление осуществляется всеми абонентами на основе протоколов без центра. Они делятся на:
	    - **Детерминированные** — порядок предоставления доступа строго определен, абоненты имеют приоритеты, гарантированное время доступа, коллизии практически исключены.
	    - **Случайные (вероятностные)** — порядок получения доступа произвольный, все станции равноправны. Не гарантируют точное время доступа, но более устойчивы к отказам и эффективны при малой интенсивности трафика.
5. В сетях с множественным доступом выделяют два основных метода управления:
	1. **Конкурентный (состязательный) доступ:** Узлы работают в полудуплексном режиме и конкурируют за среду. Одновременно передавать данные может только одно устройство.
	    - _Примеры:_ беспроводные сети (Wi-Fi), устаревшая топология «шина» Ethernet, сети Ethernet на базе концентраторов.
	2. **Управляемый (контролируемый) доступ:** Каждому узлу выделяется определенное время/очередь для использования среды (детерминированный доступ).
	    - _Примеры:_ устаревшие сети Token Ring и ARCNET.
6. **CSMA/CD (Collision Detection — обнаружение коллизий)**: Используется в проводных сетях (устаревшие Ethernet на концентраторах). Прослушивает среду перед отправкой. Если происходит одновременная передача, **обнаруживает столкновение (коллизию)** по изменению уровня сигнала, прекращает передачу, и данные отправляются повторно.
    
- **CSMA/CA (Collision Avoidance — предотвращение коллизий)**:
    
    - Используется в беспроводных сетях (Wi-Fi).
        
    - В беспроводной среде сложно обнаружить факт столкновения, поэтому метод **старается избежать (предотвратить) коллизии**.
        
    - Устройства оповещают сеть о том, на какое время они занимают канал, чтобы остальные узлы ожидали окончания передачи. Прием данных обязательно подтверждается кадром-ACK.
